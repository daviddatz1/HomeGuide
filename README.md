# HomeGuide

A modern, high-conversion landing page for HomeGuide — an AI-powered home repair assistance platform that helps homeowners diagnose and fix everyday household problems.

## Overview

HomeGuide is "FaceTime for home repairs" combined with AI troubleshooting and step-by-step DIY guidance. This landing page is designed for validation-stage demand testing and waitlist signups.

## Getting Started

Open `index.html` in any modern browser. No build step or dependencies required.

```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Or serve locally
python3 -m http.server 8000
```

## Page Structure

- **Hero** — Headline, value prop, CTA buttons, and interactive product mockup
- **Social Proof** — Waitlist count, advisor backing, safety-first messaging
- **Problem** — Four relatable homeowner pain points
- **How It Works** — Three-step visual flow
- **Features** — Five MVP feature cards (Snap a Problem, Step-by-Step Guidance, Live Expert Help, Fix vs Hire Comparison, Safety Indicator)
- **Transformation** — Before/after comparison
- **FAQ** — Accordion with five common questions
- **CTA / Waitlist** — Email capture form with success state

## Design

- Clean, minimal SaaS aesthetic (Stripe/Airbnb/Notion-level polish)
- Inter font family with strong typographic hierarchy
- Mobile-first responsive design
- Scroll-triggered fade-in animations
- Accessible: semantic HTML, ARIA attributes, keyboard navigation

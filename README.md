# HomeGuide Landing Page

A modern, high-conversion landing page for HomeGuide — a consumer home repair assistance platform that helps homeowners diagnose and fix everyday household problems using AI guidance and optional live expert video help.

## Overview

This is a validation-stage landing page designed to test demand and collect waitlist signups. It showcases the core value proposition: instant AI diagnosis of home problems, step-by-step repair guidance, and optional live expert help.

## Structure

- **Hero** — Headline, subheadline, CTA buttons, and a mock app UI showing the diagnosis flow
- **Problem** — Four relatable homeowner frustrations
- **How It Works** — Three-step flow (Snap → Diagnose → Fix)
- **Features** — Five MVP features in card layout
- **Transformation** — Before/after comparison
- **FAQ** — Accordion-style common questions
- **CTA / Waitlist** — Email capture form with toast confirmation

## Tech Stack

Single-file HTML page with:
- Inline CSS (no external dependencies beyond Google Fonts)
- Vanilla JavaScript for interactivity
- Inter font from Google Fonts
- Fully responsive (mobile-first)
- Scroll-triggered fade-in animations via Intersection Observer

## Running Locally

Open `index.html` in any modern browser. No build step or server required.
